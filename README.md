# static_code

## Inventory Management System

A Python-based inventory management system with code quality checks using Pylint.

## Features

- Add items to inventory
- Remove items from inventory
- Check item quantities
- Load and save inventory data from/to JSON files
- Check for low stock items
- Input validation and error handling
- Comprehensive logging

## Installation

1. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run the inventory system:
```bash
python3 inventory_system.py
```

## Code Quality

This project uses Pylint for code quality checks.

### Running Pylint

To check code quality:
```bash
pylint inventory_system.py
```

Current code quality rating: **9.11/10**

### Linting Configuration

The project includes a `.pylintrc` file for customized linting rules.
